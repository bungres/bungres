# Relational Query Builder

In addition to traditional SQL query builders, `@bungres/orm` includes a high-level **Relational Query API** (`db.tableName.findFirst()` & `db.tableName.findMany()`) that allows fetching deeply nested relational trees in a single clean call.

---

## Basic Relational Queries (`findFirst` & `findMany`)

```ts
import { db } from "./db";

// Fetch single user with active condition
const user = await db.users.findFirst({
  where: eq(users.email, "alice@example.com"),
});

// Fetch list of users
const allUsers = await db.users.findMany({
  where: eq(users.active, true),
});
```

---

## Nested Eager Loading (`with: { ... }`)

Fetch related parent or child records by simply enabling them in the `with` object option:

```ts
const userWithPosts = await db.users.findMany({
  with: {
    posts: true, // Automatically fetches related posts for each user!
  },
});
```

You can pass query filters to nested relations:

```ts
const userWithPublishedPosts = await db.users.findMany({
  with: {
    posts: {
      where: eq(posts.published, true),
      orderBy: desc(posts.createdAt),
      limit: 5,
    },
  },
});
```

## 🌟 Zero-Boilerplate Many-to-Many Relations

In traditional ORMs, setting up Many-to-Many relationships requires defining verbose relation definitions, explicit pivot table schema configs, and complex join declarations.

**Bungres automatically inspects your schema foreign keys to detect junction tables!**

```ts
// Schema setup: users, groups, and user_groups junction table
export const users = pgTable("users", { id: uuid({ primaryKey: true }) });
export const groups = pgTable("groups", { id: uuid({ primaryKey: true }) });

export const userGroups = pgTable("user_groups", {
  userId: uuid({ references: () => users.id, notNull: true }),
  groupId: uuid({ references: () => groups.id, notNull: true }),
});

// Query: Fetch users and automatically resolve many-to-many groups!
const usersWithGroups = await db.users.findMany({
  with: {
    groups: true, // Automatically resolved through user_groups junction!
  },
});
```
