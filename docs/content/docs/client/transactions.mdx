# Database Transactions

Transactions allow executing multiple database queries atomically. If any error is thrown inside a transaction block, all mutations are automatically rolled back.

---

## Basic Transaction API

Use `db.transaction()` to start an atomic transaction:

```ts
import { db } from "./db";
import { users, accounts } from "./db/schema";
import { eq } from "@bungres/orm";

const result = await db.transaction(async (tx) => {
  // 1. Create a user inside transaction client (tx)
  const newUser = await tx
    .insert(users)
    .values({ email: "user@example.com", username: "user1" })
    .returning()
    .single();

  // 2. Create account linked to user
  const account = await tx
    .insert(accounts)
    .values({ userId: newUser.id, balance: 1000 })
    .returning()
    .single();

  return { newUser, account };
});
```

## Transaction Isolation Control

Pass an options object to set PostgreSQL isolation level (`'READ COMMITTED'`, `'REPEATABLE READ'`, or `'SERIALIZABLE'`):

```ts
await db.transaction(
  async (tx) => {
    // Queries execute under SERIALIZABLE isolation level
    const user = await tx.select().from(users).where(eq(users.id, 1)).single();
    await tx.update(users).set({ points: (user?.points ?? 0) + 10 }).where(eq(users.id, 1));
  },
  { isolation: "SERIALIZABLE" }
);
```

## Automatic Rollback Behavior

If an exception is thrown within the transaction closure, Bungres issues a `ROLLBACK` to PostgreSQL and throws a `TransactionError` (or original error):

```ts
try {
  await db.transaction(async (tx) => {
    await tx.update(accounts).set({ balance: 500 }).where(eq(accounts.id, accA));
    
    // Simulate error (e.g., insufficient funds validation)
    throw new Error("Insufficient account funds!");

    await tx.update(accounts).set({ balance: 1500 }).where(eq(accounts.id, accB));
  });
} catch (err) {
  console.error("Transaction rolled back successfully:", err.message);
}
```

## Nested Transactions (`SAVEPOINT`)

Bungres supports nested transactions using PostgreSQL `SAVEPOINT`s:

```ts
await db.transaction(async (tx) => {
  await tx.insert(logs).values({ message: "Starting batch" });

  // Nested savepoint transaction block
  await tx.transaction(async (subTx) => {
    await subTx.insert(notifications).values({ userId: "123", text: "Welcome!" });
  });
});
```
