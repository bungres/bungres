# CLI Toolkit (`@bungres/kit`)

`@bungres/kit` is the CLI companion for Bungres ORM. It provides automated schema push, timestamped SQL migration generation, database introspection (`pull`), interactive database browser (`studio`), and interactive REPL (`tusky`).

---

## Configuration File (`bungres.config.ts`)

Create a `bungres.config.ts` file in the root of your project:

```ts title="bungres.config.ts"
import { defineConfig } from "@bungres/kit";

export default defineConfig({
  schema: "./src/db/schema.ts",   // Path to schema file or index
  out: "./bungres",                // Directory for migrations and generated schema
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});
```

## Available Commands Summary

| Command | Syntax | Description |
| :--- | :--- | :--- |
| **`init`** | `bungres init` | Initialize new project with default `bungres.config.ts` |
| **`generate`** | `bungres generate` | Generate timestamped SQL migration file from schema diff |
| **`migrate`** | `bungres migrate` | Apply pending migration `.sql` files to database |
| **`push`** | `bungres push` | Push schema directly to database without creating files (dev mode) |
| **`pull`** | `bungres pull` | Introspect existing database and generate TypeScript schema |
| **`status`** | `bungres status` | Compare database migration state vs local migration files |
| **`fresh`** | `bungres fresh` | Drop all schema tables and re-run all migrations from scratch |
| **`refresh`** | `bungres refresh` | Truncate all tables to reset data without dropping tables |
| **`seed`** | `bungres seed` | Execute database seed script |
| **`studio`** | `bungres studio` | Launch local web GUI database data browser |
| **`tusky`** | `bungres tusky` | Launch interactive Node/Bun REPL with pre-loaded DB & schema |
| **`drop`** | `bungres drop` | Drop all tables defined in schema (prompts for confirmation) |
