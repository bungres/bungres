# TypeScript & Type Inference

`@bungres/orm` provides end-to-end type safety. You can infer exact TypeScript interfaces directly from your table definitions without manually duplicating interface types.

---

## `InferTable<typeof table>`

`InferTable` extracts the full row type returned from a `SELECT` query (including auto-generated default fields, primary keys, and non-null values):

```ts
import type { InferTable } from "@bungres/orm";
import { users } from "./db/schema";

export type User = InferTable<typeof users>;

/*
Equivalent to:
type User = {
  id: string;
  email: string;
  username: string;
  fullName: string | null;
  active: boolean;
  createdAt: Date;
}
*/
```

---

## `InferInsert<typeof table>`

`InferInsert` extracts the payload shape expected for `INSERT` operations. Fields with database default expressions (e.g. `gen_random_uuid()`, `NOW()`, `default: false`) or nullable properties automatically become optional:

```ts
import type { InferInsert } from "@bungres/orm";
import { users } from "./db/schema";

export type NewUser = InferInsert<typeof users>;

/*
Equivalent to:
type NewUser = {
  id?: string;               // Optional because default gen_random_uuid() exists
  email: string;             // Required (notNull: true)
  username: string;          // Required (notNull: true)
  fullName?: string | null;  // Optional
  active?: boolean;          // Optional because default: false exists
  createdAt?: Date;          // Optional because defaultRaw: "NOW()" exists
}
*/
```

---

## Function Parameter Example

Use inferred types across your application logic and API endpoints:

```ts
import { db } from "./db";
import { users } from "./db/schema";
import type { InferInsert } from "@bungres/orm";

export async function createNewUser(payload: InferInsert<typeof users>) {
  return await db.insert(users).values(payload).returning().single();
}
```
