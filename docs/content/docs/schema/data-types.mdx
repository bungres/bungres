# Column Data Types

`@bungres/orm` supports all standard PostgreSQL data types out of the box with total TypeScript type inference.

---

## Primary Keys & Serial Types

```ts
import { uuid, serial, bigserial, smallserial } from "@bungres/orm";

// UUID Primary Key (auto-generates gen_random_uuid() in PostgreSQL)
id: uuid({ primaryKey: true })

// Serial auto-incrementing integer types
id: serial({ primaryKey: true })        // 4-byte auto-increment integer
bigId: bigserial({ primaryKey: true })   // 8-byte auto-increment integer
smallId: smallserial()                  // 2-byte auto-increment integer
```

---

## Strings & Text

```ts
import { text, varchar, char } from "@bungres/orm";

name: text()                                   // Unlimited length text
email: varchar({ length: 255, notNull: true }) // Varchar with max length
code: char({ length: 10 })                     // Fixed length character
```

---

## Numbers & Numeric Types

```ts
import { integer, bigint, smallint, real, doublePrecision, numeric, decimal } from "@bungres/orm";

count: integer()             // 32-bit signed integer
bigCount: bigint()           // 64-bit signed integer
age: smallint()              // 16-bit signed integer
rating: real()               // Single precision floating point (float4)
coordinate: doublePrecision()// Double precision floating point (float8)
price: numeric()             // Arbitrary precision numeric
amount: decimal()            // Exact decimal value
```

---

## Booleans

```ts
import { boolean } from "@bungres/orm";

active: boolean({ default: true, notNull: true })
```

---

## Dates & Timestamps

```ts
import { timestamptz, timestamp, date, time, timetz, interval } from "@bungres/orm";

createdAt: timestamptz({ defaultRaw: "NOW()", notNull: true }) // Timestamp with time zone
updatedAt: timestamp()                                         // Timestamp without time zone
dob: date()                                                   // Date (YYYY-MM-DD)
shiftStart: time()                                            // Time of day
shiftEnd: timetz()                                            // Time of day with time zone
duration: interval()                                          // Time interval span
```

---

## JSON & Structured Objects

```ts
import { json, jsonb } from "@bungres/orm";

metadata: json()                               // Stored as unparsed JSON text
settings: jsonb({ default: { theme: "dark" } }) // Binary JSONB (indexable & queryable)
```

---

## Arrays

Any standard column can be converted into a PostgreSQL array type using the `.array()` helper method or explicit array builders:

```ts
import { text, integer, uuid, textArray, integerArray } from "@bungres/orm";

// Fluent array extension on any column
tags: text().array()
scores: integer().array()

// Built-in array helpers
categories: textArray()
numbers: integerArray()
```

---

## PostgreSQL Enums

Create type-safe Postgres ENUM types with `pgEnum()`:

```ts
import { pgEnum, pgTable, uuid, text } from "@bungres/orm";

// 1. Declare Postgres ENUM
export const roleEnum = pgEnum("user_role", ["admin", "editor", "viewer"]);

// 2. Use in table schema
export const users = pgTable("users", {
  id: uuid({ primaryKey: true }),
  role: roleEnum({ default: "viewer", notNull: true }),
});
```

## Custom & Network Types

```ts
import { inet, cidr, macaddr, bytea, customType } from "@bungres/orm";

ipAddress: inet()            // IPv4 or IPv6 network address
subnet: cidr()               // CIDR network block
mac: macaddr()               // Hardware MAC address
binaryData: bytea()          // Binary data buffer

// Custom type wrapper for specialized domain types
const pointType = customType<[number, number]>("point");
location: pointType("location")
```
