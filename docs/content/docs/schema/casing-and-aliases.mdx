# Casing API & Column Aliases

Bungres simplifies working with PostgreSQL database column naming conventions by providing **automatic casing transformation** and **expressive column aliasing**.

---

## Automatic Casing Transformation

In JavaScript and TypeScript, the standard convention is `camelCase` (e.g., `fullName`, `createdAt`). In PostgreSQL, standard column naming conventions prefer `snake_case` (e.g., `full_name`, `created_at`).

With Bungres, **you don't have to manually write string column names for every single property**. Bungres automatically converts JavaScript property names into `snake_case` database column names under the hood!

```ts
import { pgTable, uuid, text, timestamptz } from "@bungres/orm";

export const users = pgTable("users", {
  id: uuid({ primaryKey: true }),
  
  // Property: fullName  -->  Postgres Column: full_name
  fullName: text(),
  
  // Property: emailVerified  -->  Postgres Column: email_verified
  emailVerified: text(),
  
  // Property: createdAt  -->  Postgres Column: created_at
  createdAt: timestamptz({ defaultRaw: "NOW()" }),
});
```

When Bungres generates `CREATE TABLE` DDL queries or executes `INSERT` / `SELECT` statements, it handles the conversion automatically:

```sql
-- DDL generated by @bungres/kit
CREATE TABLE "users" (
  "id" uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  "full_name" text,
  "email_verified" text,
  "created_at" timestamptz DEFAULT NOW()
);
```

---

## Opting Out of Automatic Casing

If you want exact matching without casing transformation, call `noCasing()` or supply explicit column names:

```ts
import { pgTable, text, noCasing } from "@bungres/orm";

// Explicit custom column name
export const customTable = pgTable("custom_table", {
  // Specify explicit column name as first argument
  customCol: text("my_custom_db_col_name"),
});
```

## Column Aliasing (`.as()`)

When building `SELECT` queries, you can dynamically rename columns in query results using the `.as()` method on any column definition:

```ts
import { users } from "./schema";

const results = await db
  .select(
    users.id,
    users.fullName.as("userName"),       // Renames 'full_name' result key to 'userName'
    users.createdAt.as("registrationDate")// Renames 'created_at' result key to 'registrationDate'
  )
  .from(users);

// TypeScript infers the exact aliased keys:
// results: Array<{ id: string; userName: string | null; registrationDate: Date }>
```

Column aliasing works seamlessly in aggregations, subqueries, and expressions:

```ts
import { count } from "@bungres/orm";

const summary = await db
  .select(
    count(users.id).as("totalUsers")
  )
  .from(users);

console.log(summary[0].totalUsers);
```
