# Insert Query Builder

The `InsertBuilder` manages single and batch record insertions, returning clauses, chunked bulk operations, and conflict resolution (upserts).

---

## Single Record Insertion

```ts
import { users } from "./db/schema";

const newUser = await db
  .insert(users)
  .values({
    email: "carol@example.com",
    username: "carol",
    fullName: "Carol Danvers",
  })
  .returning()
  .single();
```

---

## Bulk Batch Insertion (`.values()`)

Pass an array of objects to insert multiple rows in a single batch query:

```ts
const createdUsers = await db
  .insert(users)
  .values([
    { email: "dev1@bungres.io", username: "dev1" },
    { email: "dev2@bungres.io", username: "dev2" },
    { email: "dev3@bungres.io", username: "dev3" },
  ])
  .returning();
```

---

## Chunked Bulk Insertion (`bulkInsert`)

For inserting large datasets (thousands of rows) without exceeding PostgreSQL query parameter limits, use `bulkInsert(data, batchSize?)`:

```ts
const largeDataset = Array.from({ length: 5000 }, (_, i) => ({
  email: `user${i}@example.com`,
  username: `user_${i}`,
}));

// Inserts in chunks of 1000 (default batchSize)
const insertedUsers = await db
  .insert(users)
  .returning()
  .bulkInsert(largeDataset, 1000);
```

## Upsert Handling (`onConflictDoUpdate` / `onConflictDoNothing`)

Handle primary key or unique index conflicts effortlessly:

### 1. Ignore Conflicts (`onConflictDoNothing`)

```ts
await db
  .insert(users)
  .values({ email: "alice@example.com", username: "alice" })
  .onConflictDoNothing();
```

### 2. Update on Conflict (`onConflictDoUpdate`)

```ts
const user = await db
  .insert(users)
  .values({
    email: "alice@example.com",
    username: "alice_updated",
    active: true,
  })
  .onConflictDoUpdate({
    target: users.email,
    set: {
      username: "alice_updated",
      active: true,
    },
  })
  .returning()
  .single();
```
