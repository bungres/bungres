# Delete Query Builder

The `DeleteBuilder` lets you remove records from database tables or perform soft deletion.

---

## Basic Delete

```ts
import { users } from "./db/schema";
import { eq } from "@bungres/orm";

// Delete user by ID
await db
  .delete(users)
  .where(eq(users.id, userId));
```

---

## Delete with Returning

Return deleted records to inspect or archive deleted data:

```ts
const deletedUser = await db
  .delete(users)
  .where(eq(users.id, userId))
  .returning()
  .single();

console.log("Deleted record:", deletedUser);
```

---

## Soft Delete (`softDelete`)

Transform a DELETE query into an `UPDATE` that sets a `deletedAt` timestamp (default: `"deletedAt"`):

```ts
import { eq } from "@bungres/orm";
import { users } from "./db/schema";

// Updates "deleted_at" column to current timestamp instead of hard deletion
await db
  .delete(users)
  .where(eq(users.id, userId))
  .softDelete("deletedAt");
```

---

## Bulk Batch Delete (`bulkDelete`)

Execute deletions across multiple condition items and return total deleted count:

```ts
import { eq } from "@bungres/orm";
import { users } from "./db/schema";

const deletedCount = await db.delete(users).bulkDelete([
  eq(users.id, 101),
  eq(users.id, 102),
  eq(users.id, 103),
]);

console.log(`Deleted ${deletedCount} records.`);
```
