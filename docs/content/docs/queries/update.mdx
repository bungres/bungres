# Update Query Builder

The `UpdateBuilder` lets you mutate existing rows in PostgreSQL safely.

---

## Basic Update

```ts
import { users } from "./db/schema";
import { eq } from "@bungres/orm";

const updatedUser = await db
  .update(users)
  .set({
    fullName: "Alice Vance-Smith",
    active: true,
  })
  .where(eq(users.id, userId))
  .returning()
  .single();
```

---

## Updating Multiple Records

Modify the `.where()` clause to update multiple rows matching a condition:

```ts
import { eq } from "@bungres/orm";
import { users } from "./db/schema";

await db
  .update(users)
  .set({ active: false })
  .where(eq(users.verified, false));
```

---

## Bulk Batch Update (`bulkUpdate`)

Execute multiple update items sequentially in a single helper method:

```ts
import { eq } from "@bungres/orm";
import { users } from "./db/schema";

await db.update(users).bulkUpdate([
  { where: eq(users.id, 1), set: { fullName: "Alice" } },
  { where: eq(users.id, 2), set: { fullName: "Bob" } },
  { where: eq(users.id, 3), set: { fullName: "Charlie" } },
]);
```
