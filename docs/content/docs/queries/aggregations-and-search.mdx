# Aggregations & Full-Text Search

---

## Aggregate Functions

Bungres provides aggregate functions for SQL summary and statistical calculations:

| Function | Description | SQL Output |
| :--- | :--- | :--- |
| `count(col?)` | Count non-null items or `COUNT(*)` | `COUNT(col)` |
| `sum(col)` | Sum of column values | `SUM(col)` |
| `avg(col)` | Average of column values | `AVG(col)` |
| `min(col)` | Minimum value | `MIN(col)` |
| `max(col)` | Maximum value | `MAX(col)` |
| `stddev(col)` | Standard deviation | `STDDEV(col)` |
| `variance(col)` | Variance | `VARIANCE(col)` |

```ts
import { count, sum, avg, min, max, stddev, variance } from "@bungres/orm";
import { orders } from "./db/schema";

const summary = await db
  .select(
    count(orders.id).as("totalOrders"),
    sum(orders.totalAmount).as("revenue"),
    avg(orders.totalAmount).as("averageOrderValue"),
    stddev(orders.totalAmount).as("stdDevValue"),
    variance(orders.totalAmount).as("varianceValue")
  )
  .from(orders);
```

## Window Functions & Ranking (`over()`, `rowNumber()`, `rank()`, `denseRank()`)

Add window partitions and ordering using `over()` or dedicated window helpers:

```ts
import { count, over, rowNumber, rank, denseRank } from "@bungres/orm";
import { employees } from "./db/schema";

const results = await db
  .select(
    employees.name,
    employees.departmentId,
    employees.salary,
    rowNumber({ partitionBy: employees.departmentId, orderBy: { column: employees.salary, dir: "desc" } }).as("rowNum"),
    rank({ partitionBy: employees.departmentId, orderBy: { column: employees.salary, dir: "desc" } }).as("rankNum"),
    denseRank({ partitionBy: employees.departmentId, orderBy: { column: employees.salary, dir: "desc" } }).as("denseRankNum")
  )
  .from(employees);
```

## Full-Text Search

Execute fast, indexed PostgreSQL full-text search queries using vector matching:

```ts
import { toTsvector, plainToTsquery, tsMatch } from "@bungres/orm";
import { articles } from "./db/schema";

const searchResults = await db
  .select()
  .from(articles)
  .where(
    tsMatch(
      toTsvector("english", articles.content),
      plainToTsquery("english", "high performance orm")
    )
  );
```
