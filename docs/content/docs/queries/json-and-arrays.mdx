# JSON & Array Query Operators

PostgreSQL offers rich capabilities for querying JSONB documents and array columns. `@bungres/orm` provides dedicated operators for JSON and Array filtering.

---

## JSONB Operators

```ts
import { 
  containsJson, 
  containedInJson, 
  hasKey, 
  hasAnyKeys, 
  hasAllKeys, 
  jsonExtract, 
  jsonExtractText 
} from "@bungres/orm";
```

### 1. JSON Containment (`containsJson` & `containedInJson`)

```ts
// Check if metadata column contains JSON matching object
db.select().from(users).where(
  containsJson(users.metadata, { theme: "dark", notifications: true })
);

// Reverse containment check
db.select().from(users).where(
  containedInJson(users.metadata, { theme: "dark", notifications: true, lang: "en" })
);
```

### 2. Key Existence (`hasKey`, `hasAnyKeys`, `hasAllKeys`)

```ts
// Check if top-level key exists in JSONB object
db.select().from(users).where(hasKey(users.settings, "betaFeatures"));

// Check if ANY key in array exists
db.select().from(users).where(hasAnyKeys(users.settings, ["theme", "mode"]));

// Check if ALL keys exist
db.select().from(users).where(hasAllKeys(users.settings, ["email", "phone"]));
```

### 3. Extracting JSON Fields (`jsonExtract` & `jsonExtractText`)

```ts
// Extract JSON value (#>) or text value (#>>)
db.select(
  jsonExtractText(users.metadata, "profile", "avatarUrl").as("avatar")
).from(users);
```

## Postgres Array Operators

```ts
import { arrayContains, arrayContained, arrayOverlaps } from "@bungres/orm";

// Check if array column contains values
db.select().from(posts).where(arrayContains(posts.tags, ["bun", "postgres"]));

// Check if array overlaps with another array
db.select().from(posts).where(arrayOverlaps(posts.tags, ["bun", "ts", "js"]));
```
